# 2026 简谱 · 动态曲谱播放器（网页版）

纯静态站点，可托管于 GitHub Pages，随时随地用浏览器打开。

## 功能
- 192 首曲谱名称按钮网格 + 搜索过滤
- 曲谱详情页：图片滚动展示、节拍器（BPM / 拍型 / 摆锤动画 / 击拍声）
- 两种滚动模式：高亮条 / 平滑滚动
- 播放 / 暂停控制，三档速度（慢 / 中 / 快）

## 部署
1. 推送到 GitHub 仓库
2. 仓库 Settings → Pages → Source 选 `main` 分支（根目录）
3. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

图片已全部重命名为 ASCII 文件名（img0001.JPG …），避免中文路径问题。
